# FluentC2 AI — Android APK

This project packages the supplied FluentC2 AI HTML application inside a native Android WebView.

## Build APK with GitHub Actions

1. Create a new **public or private** GitHub repository (for example `FluentC2-Android`).
2. Upload the complete contents of this folder to the repository root. The `.github/workflows/build-apk.yml` file must remain in that exact path.
3. Open the repository's **Actions** tab and select **Build FluentC2 Android APK**.
4. Select **Run workflow**. A push to `main` or `master` also starts a build automatically.
5. When the run completes, open it and download the artifact named **FluentC2-AI-debug-apk**.
6. Extract the ZIP and install `app-debug.apk` on Android. If prompted, allow installation from that source.

## Gemini AI setup

The supplied HTML has no Gemini API key. The app therefore works for its bundled lessons, library, progress UI, speech and pronunciation tools, but Gemini conversation and AI sentence generation remain unavailable until a key is configured.

After obtaining a Gemini API key, tap **API** in the app header and paste the key. It is stored in this app's local WebView storage on this device. Do not share the APK containing a personal key or publish the key in GitHub. A production deployment should use a server-side proxy so the API key is not exposed in a client app.

## Included native Android support

- Android WebView wrapper with persistent DOM storage and internet access.
- Android Text-to-Speech for English playback.
- Android SpeechRecognizer fallback for microphone practice.
- Runtime microphone permission request.
- GitHub Actions workflow that builds and uploads a debug APK artifact.

## Notes

- This is a **debug APK**, suitable for testing and sideloading. A signed release APK/AAB requires a release keystore and protected GitHub secrets.
- The HTML's Tailwind, Google Fonts and Font Awesome resources are loaded from their existing CDN URLs, so a network connection is needed for the full original styling.
- No Gemini key is included or generated by this project.
